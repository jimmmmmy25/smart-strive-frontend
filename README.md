# SMART STRIVE — React Mockup Starter

This is a React + Vite starter based on the SMART STRIVE mockup.

## Use with your existing project

1. Open your existing `SMART-STRIVE` folder in VS Code.
2. Keep your existing `node_modules`, `package-lock.json`, and `package.json`.
3. Copy the `src` folder from this package into your project and replace the existing `src` folder.
4. Make sure `index.html` contains:
   `<script type="module" src="/src/main.jsx"></script>`
5. In VS Code Terminal run:
   `npm run dev`

## If you want to test this package as a separate project

Extract it, open the extracted folder in VS Code, then run:
`npm install`
`npm run dev`
